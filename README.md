# mi-web

Tu web de captación: una página principal y una landing por avatar, con el formulario de EOS.

**Cómo se usa:** entras a [claude.ai/code](https://claude.ai/code), eliges este repositorio y le pides lo que necesitas. Por ejemplo:

> Créame una landing para mineros que trabajan por turnos en el norte.

Claude la arma y te deja un pull request. Ahí entras a **Visit Preview** para mirarla. Si te gusta, aprietas **Merge pull request** y en un minuto está publicada en tu dominio.

Las reglas que sigue Claude están en `CLAUDE.md`.
